- Add block, flexbox and grid layout with static, sticky and fixed positions, intrinsic sizes, stacking order, right-to-left subtrees and paddings and margins that follow the safe area and the software keyboard.

- Add transitions, keyframes, animated values, motion presets and layout animations of a commit or of one view's size and position, which run on each platform's frame clock (#19 by @oneo-me).
- Add selectable, hit-testable rich text with the app's fonts, OpenType figures and small capitals, decoration lines of any style, thickness and offset, inputs, GIF, WebP and SVG images, Canvas 2D drawing, GPU shaders written in Go and Lucide icons.
- Add scroll views with overlay scroll bars, touch scrolling, throttled scroll events, pull to refresh, the app's own refresh indicators and edge effects under its bars, virtualized lists, overlays, modals, navigation stacks with system headers and iOS's system bar buttons, iOS's sliding pushes and pops, predictive back and browser history, the system tab bar and leaving the app in `mobile`, web views, videos and native views.
- Add pointer, touch, focus, keyboard and gesture input, file drops, accessibility, storage and environment signals.
- Add clipboard images and files, opening links, the photo picker, file pickers and save dialogs for files of any type, folder pickers on desktops, opening the app's files in other apps and sharing them through the system's share sheet, handing APKs to Android's installer, forced light or dark appearance and a disk cache for downloaded images (#22 by @oneo-me, #16, #17 and #18 by @westhiker).
- Add apps that open their own windows, panels, tray icons and global shortcuts on one engine, with shutdown modes, the Dock and launch at login on macOS, and custom title bars with placed or hidden window controls, window frames, levels and materials, and application and context menus in `desktop`, with scroll bars and a return from `nsgo.Run` on quit.
- Add `base`: unstyled controls, popups whose entry and exit the app's classes animate, menus that become sheets on phones, dialogs, sheets, swipeable toasts, resizable panels with the app's handles, a dock rearranged from its ref, charts, tables, a `DataTable` over a million rows, a streaming `TextView` that reports its images and opens its links, a code `Editor` with completion, a language server's edits and folds by level, and a `DiffView` with review comments and the app's separators and file headers (#11 by @oneo-me).

- Add `nsgotest` for app tests that act as a user does, headless or on every platform with its native input, menus and screenshots, the test's own clock and clipboard.
- Add the `nsgo` tool, which creates Go, TSX and mixed apps, runs them with hot reload and commit traces, tests them, from scripts on standard input too and with performance readings on platforms, type-checks, packages and signs them for stores from `nsgo.yaml`, reporting each step and each package's build time and size.

- Add `ui`: styled components on `base` in Onevra's look, a theme and a conversation in `ui/chat`, for apps to use as they are.
- Add NSH's gallery translated to Go, with a demo of every element, component and service, components grouped by what they do with their props to set and a whole page for each complex one, its editor talking to a simulated language server and its AI Chat on Onevra's conversation components, in English, Chinese and Arabic.
